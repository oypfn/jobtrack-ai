# JobTrack AI

A career-search workspace to organize applications, stages and job-search progress.

## Current milestone
Responsive React + TypeScript frontend with application creation, pipeline stages, search, stage counts and browser-local persistence. Demo records are illustrative only.

## Run locally

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm test
npm run build
```

## Roadmap

- [x] Add, update stage, search and delete workflows

- [ ] Privacy controls, export and deletion
- [ ] End-to-end tests and deployment

## Responsible AI
AI suggestions must be explainable and editable, never make hiring decisions. CV and job data are personal information. Do not upload personal documents until authentication, retention, consent and provider data-handling policies are implemented.
